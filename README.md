# Ecommerce_Analysis
This dataset contains customer, product, order, and review data from an online retail platform. Each row represents an order transaction with associated customer and product details. On this project i will create a Database through SQL and next i will analyze my data.

Project Overview steps:
-- Create a database for Ecommerce Analysis
-- Project Structure, Logging And Exception Handling
-- EDA And Model Training 
-- Data Ingestion
-- Data Transformation
-- Model Trainer
-- Predict Pipeline
-- Model Deployment on AWS

## Database and SQL quering.## 
The queries i will try to answer (using SQL) in order to gain deeper knowledge about my data are:

Basic Queries

1.	Retrieve all columns for all orders.
2.	Get all orders that are 'Completed'.
3.	Retrieve order_id, customer_id, order_date, and order_status for all orders.
4.	List products sorted by unit_price in descending order.
5.	Count the total number of orders.

Aggregations & Grouping

1.	Calculate total revenue (quantity * unit_price) for each product.
2.	Count how many orders each customer has placed.
3.	Calculate the average total amount spent per customer.
4.	Count the number of orders for each country.
5.	Find the average rating for each product.

Joins & Relationships

1.	List all orders along with customer first and last names and order status.
2.	List products with average rating above 4.5 along with the number of reviews.
3.	Get all orders where a review has been submitted, including review_text.

Advanced Queries

1.	Find the top 5 customers who spent the most in total.
2.	Calculate total sales per month.
3.	Find the percentage of orders that were cancelled.
4.	Identify the most purchased product in each country.
5.	Count how many customers made more than one order.
6.	List customers who wrote the most reviews.
7.	Find the average rating given by customers for products in their first order.
